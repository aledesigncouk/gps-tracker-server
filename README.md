
# Nautilus Tracker (server side)

Backend of the Nautilus trips tracker, an application that can display tracks generated by GPS trackers. It enable a simple interface to uplad .csv data into a MySQL DB and provide some endpoints for the Frontend.

## Secret credentials
API key and Database credential need to be stored in a .env file, that can be autogenerated at deployment time by actions.


## CSV input format
CSV file rows must contain the first three fields formatted in the following way:
DD/MM/YYYY HH:MM:SS, latitude, longitude
01/09/2023 00:35:55,52.66646,-2.4749416, [ ... ]
